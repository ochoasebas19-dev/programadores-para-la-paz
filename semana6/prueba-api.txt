Al enviar una petición POST a la ruta /registro con un JSON que contiene el nombre y un mensaje, el servidor recibe los datos mediante req.body y devuelve una respuesta en formato JSON confirmando que los datos fueron recibidos correctamente.

Ejemplo de respuesta:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}
