El login permite identificar a cada usuario antes de acceder a una aplicación.
Gracias a la autenticación, solo las personas autorizadas pueden ingresar a determinadas funciones.
Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar cambios importantes.
Esto ayuda a mantener la seguridad del sistema.
No deben exponerse públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de los usuarios.
